# Support-Operations-Analytics
Tableau Support Operations Analytics dashboard analyzing ticket volume, SLA performance, team workload, customer impact and ticket-level investigation.

## Business Objectives

- Monitor overall support performance
- Identify SLA risks
- Analyze team workload
- Identify high-risk categories
- Understand customer impact
- Investigate individual tickets

## Tools

- Tableau
- SQL
- Data Analysis

## Dashboards

1. Executive Overview
2. SLA & Operations Performance
3. Root Cause & Customer Impact
4. Ticket Investigation

## Key Analysis

- Ticket Volume
- SLA Compliance
- SLA Breach Rate
- Escalation Rate
- Team Workload
- Customer Impact
- Investigation Priority
- Team Workload vs SLA Risk
